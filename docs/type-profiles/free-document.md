# Free document

ID: `free-document` · Status: **Planned — not creatable** · Groups: General purpose.

Write a structured document without a specialized header; scope remains to be defined.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Optional title, author and date.
- General document settings.

## Capability needs

- Core rich text, sections, lists, images, tables and footnotes.
- Assess optional bibliography without inheriting all specialist capabilities.

## First useful model

A neutral document with no required specialized heading.

## Decisions and open questions

- Clarify its difference from Report.
- Free means freedom of structure, not arbitrary page-layout controls.
