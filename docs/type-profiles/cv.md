# CV

ID: `cv` · Status: **Planned — not creatable** · Groups: Careers and applications.

Organize experience, education and skills for an application.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Identity, professional headline and contact details.
- Experiences, education and skills.
- Optional languages, publications and other activities.

## Capability needs

- Repeatable dated records with rich descriptions.
- Optional publication list and links.

## First useful model

A restrained readable CV usable for a professional or academic application.

## Decisions and open questions

- Agree the common record structure before adding specialist academic variants.
- Decide which personal details are optional; never require a photograph.
