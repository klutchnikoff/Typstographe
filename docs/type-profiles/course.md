# Course material

ID: `course` · Status: **Planned — not creatable** · Groups: Teaching.

Write structured teaching material with explanations, examples, illustrations and references.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Title, author, institution and teaching unit.
- Optional audience, academic year and learning objectives.

## Capability needs

- Sections, contents, figures, tables, notes and bibliography.
- Examples, callouts, equations and code when needed.

## First useful model

A clear printable course handout.
