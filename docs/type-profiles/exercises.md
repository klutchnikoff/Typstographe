# Exercises and assessments

ID: `exercises` · Status: **Planned — not creatable** · Groups: Teaching.

Prepare exercises, assignments or examinations with instructions and optional solutions.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Title, teaching unit, author and optional date.
- Optional duration, permitted materials and marking information.

## Capability needs

- Exercises, questions and nested question parts.
- Optional solutions, equations, figures and tables.

## First useful model

A readable exercise sheet with optional solutions.

## Decisions and open questions

- Decide the shared contract for exercises and assessments.
- Solutions are content; their inclusion in a particular output must be an explicit choice.
