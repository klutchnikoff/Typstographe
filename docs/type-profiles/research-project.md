# Research proposal

ID: `research-project` · Status: **Planned — not creatable** · Groups: Research and publications, Careers and applications.

Present a doctoral project or funding application: objectives, methods, schedule and resources.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Project title, optional acronym and summary.
- Applicants, partners and institutions.
- Call or target program, duration and requested resources.

## Capability needs

- Structured sections, citations, bibliography, figures and tables.
- Schedule, work packages and budget if their need is confirmed.

## First useful model

A sober proposal suitable for a doctoral project or funding application.

## Decisions and open questions

- Use one type initially; validate the shared core of doctoral and funding proposals.
- Distinguish optional fields from requirements imposed by a funding call.
- This document type is not the .typsto project container.
