# Presentation

ID: `presentation` · Status: **Planned — not creatable** · Groups: Correspondence and administration, Research and publications, Teaching, Books and communication.

Prepare slides for a meeting, a class or a scientific talk.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Title, speakers and affiliations.
- Optional event, date and contact details.

## Capability needs

- Slides, sections, figures, tables, equations and citations.
- Speaker notes if their need is confirmed.

## First useful model

A sober slide deck with clear titles and large readable text.

## Decisions and open questions

- Define semantic slide boundaries without exposing layout code.
- Distinguish slide content, speaker notes and model-specific composition.
