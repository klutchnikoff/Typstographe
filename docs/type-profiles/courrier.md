# Letter

ID: `courrier` · Status: **Available** · Groups: Correspondence and administration, Careers and applications.

Write personal or professional correspondence with recipient details, signature and attachment mentions.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Sender and recipient contact details.
- Subject, reference, place and optional fixed date.
- Optional signature image.

## Capability needs

- Rich text, headings, lists, links, images and tables.
- Postscript and attachment mentions.

## First useful model

A restrained personal letter, including the layout for a window envelope.

## Decisions and open questions

- A cover letter is a use of Letter, not a separate document type.
