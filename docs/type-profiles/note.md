# Note

ID: `note` · Status: **Planned — not creatable** · Groups: Correspondence and administration.

Present information, a short analysis or a recommendation to identified recipients.

This is a product profile, not an executable metadata or Typst signature.
For available types, the implemented contract and capability catalogue remain authoritative.
For planned types, the following needs are provisional and require joint validation before coding.

## Information to capture

- Title, writer, date and intended recipients.
- Optional subject and reference.

## Capability needs

- Headings, lists, quotations, images, tables and footnotes.

## First useful model

A concise internal note with a clear heading.

## Decisions and open questions

- Keep memo and briefing note as uses of one type unless their contracts diverge.
